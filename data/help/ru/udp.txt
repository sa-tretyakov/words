## udp.Open
udp.Open port → u8
Открывает UDP-сокет на порту. Возвращает индекс (0-7) или 0xFF.
Пример: 5000 udp.Open -> sock

## udp.Multicast
udp.Multicast ip port → u8
Открывает UDP-сокет для multicast-группы.
Пример: "239.1.1.1" 5000 udp.Multicast -> sock

## udp.Close
udp.Close sock → BOOL
Закрывает UDP-сокет.
Пример: udp.Close sock

## udp.Send
udp.Send sock ip port data → BOOL
Отправляет данные через UDP.
Пример: udp.Send sock "192.168.1.100" 5000 "Hello"

## udp.Available
udp.Available sock → u16
Количество байт в принятом пакете. 0 если нет данных.
Пример: udp.Available sock -> bytes

## udp.Recv
udp.Recv sock array → u16 ip port
Принимает UDP-пакет в массив. Возвращает длину, IP и порт.
Пример: udp.Recv sock buf -> len ip port

## udp.Timeout
udp.Timeout sock ms → BOOL
Устанавливает таймаут UDP в миллисекундах.
Пример: udp.Timeout sock 2000

## out>udp
out>udp sock ip port
Перенаправляет весь вывод (print) в UDP-сокет.
Пример: out>udp sock "192.168.1.100" 5000
